# In-match pause menu

## Description
There is no way to pause or leave a match. Add a pause menu (resume, restart match, return to character select, quit) in both the web and native builds, reachable from keyboard and gamepad.

## Acceptance Criteria
- [ ] Pause freezes the simulation and audio
- [ ] Resume, restart, back to select and quit work on both targets
- [ ] Gamepad Start and keyboard Escape open it
