# Module: setup
**Role:** Renders the match setup screen once a stage is chosen: two independent `role="radiogroup"` sections — round count and time limit — each with its own heading, gating Continue on both having a selection. "Unlimited" is a first-class tagged time-limit value, never a numeric sentinel. A misconfigured option set (an even/non-positive round count, a non-positive time limit) renders a blocking, named error state instead of a default selection. Also renders a read-only Controls section listing both players' default keyboard bindings (sourced from `modules/input.md`) plus a note about gamepad support and its keyboard fallback — hidden on the error state. UI text is localized (backlog item 009): the screen holds in-progress round/time picks in local closures that a full re-render would destroy, so it subscribes to `modules/i18n.md`'s `onLocaleChange` internally and re-translates only its already-rendered text (headings, Continue, option labels, the Controls section, the blocking error state) in place. The round option label reads "Rounds: {{value}}" rather than a pluralized "N Round(s)", avoiding plural-form catalog entries for a fixed small option set. The Controls section's semantic direction labels ("Up"/"Down"/"Left"/"Right") are translated; the physical key/button names shown next to them are not.
**Files:** `src/setup/setup-screen.ts`
**Exports:** `renderSetupScreen(root, options): void`, `SetupScreenOptions`, `MatchSetupConfig`, `TimeLimitOption`, `isValidRoundCount(value): boolean`, `isValidTimeLimitOption(value): boolean`
**Depends on:** `modules/input.md` (`DEFAULT_KEYBOARD_BINDINGS`, `keyLabel`, `BUTTON_NAMES`, for the Controls section), `modules/i18n.md`
