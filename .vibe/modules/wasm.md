# Module: wasm
**Role:** One bridge per WASM dependency, each its own Go program with its own runtime instance: `bridge.ts` bridges to the `character` WASM module, `stage-bridge.ts` bridges to the `stage` WASM module, `engine-bridge.ts` bridges to the `engine` WASM module (combat simulation). All expose a typed loader/caller returning either the result or a descriptive error, never throwing. `bridge.ts`/`stage-bridge.ts` additionally expose batched `resolveSprites()` (decoded pixel data for a set of sprite references); `stage-bridge.ts` also exposes `resolveAnimationFrames()` (which sprite an animated BG element currently shows). `engine-bridge.ts` differs in call shape: every exposed function takes/returns one JSON-encoded request/response rather than typed arguments, so it also owns the JSON encode/decode at the boundary; it exposes only `newMatch`/`tick`/`closeMatch` (not `resetRound` — round-transition flow is out of scope here, see `.vibe/decisions/004`).
**Files:** `src/wasm/bridge.ts`, `src/wasm/types.ts`, `src/wasm/stage-bridge.ts`, `src/wasm/stage-types.ts`, `src/wasm/engine-bridge.ts`, `src/wasm/engine-types.ts`
**Exports:** `loadCharacter(defBytes, airBytes, sffBytes, cnsBytes, options?): Promise<CharacterResult>`, `resolveSprites(sffBytes, requests, overrideBytes?, options?): Promise<SpritePixelResult[]>`, `resetWasmBridgeForTests(): void`, `WasmBridgeOptions`, `CharacterSummary`, `CharacterResult`, `loadStage(defBytes, options?): Promise<StageResult>`, `resolveSprites` (stage), `resolveAnimationFrames(requests, options?): Promise<{ok, sprites}|{ok, error}>`, `resetStageWasmBridgeForTests(): void`, `StageWasmBridgeOptions`, `StageSummary`, `StageResult`, `newMatch(request, options?): Promise<EngineResult<NewMatchResponseData>>`, `tick(request, options?): Promise<EngineResult<TickResponseData>>`, `closeMatch(matchId, options?): Promise<EngineResult<{}>>`, `resetEngineWasmBridgeForTests(): void`, `EngineWasmBridgeOptions`
**Depends on:** (none — talks directly to the `character`/`stage`/`engine` WASM modules)
