# Module: hud
**Role:** The in-match HUD: each player's lifebar and power/meter bar, and the round display (round number, each player's round wins, best-of). `hud-view-model.ts` is pure validation/derivation: treats `engine`'s raw `MatchState`/`Progress` as untrusted `unknown` data (the WASM bridge's own JSON decoding only type-asserts, never validates) and returns either a fully valid `HudViewModel` (each fighter's health/power clamped to a `[0, 100]` percentage of the app's placeholder maxima) or one descriptive error — never a partially-valid result, so the HUD always degrades as one unit, not per field (see `.vibe/decisions/009`). A fighter's health/power must be a finite number `>= 0` to count as valid; exactly `0` is a normal KO/empty-meter reading, never confused with the error state. `hud-renderer.ts` builds the HUD's DOM once (`createHud`, each bar a `role="progressbar"` with a real `aria-valuemin`/`aria-valuemax` range — never a hardcoded 100 — plus a human-readable `aria-valuetext`/visible value-text span) and mutates it in place on every `update(state, progress)` call, never rebuilding. A derivation error swaps the whole HUD into one labeled, translated error region (mirroring `setup/setup-screen.ts`'s own blocking-error-state shape) instead of a broken or frozen bar; a later valid update recovers automatically. A round-number or win-count change fires exactly one `aria-live` announcement; an ordinary health/power-only update never does, to avoid flooding assistive tech every simulation tick. Static labels (bar `aria-label`s, the round/wins text, the error message) go through this app's `t()`/`onLocaleChange` convention, re-translating in place on a live locale switch without losing the last known values; `dispose()` releases that subscription.
**Files:** `src/hud/hud-view-model.ts`, `src/hud/hud-renderer.ts`
**Exports:** `clampPercent(value, max): number`, `deriveHudViewModel(state, progress, maxHealth, maxPower): HudViewModelResult`, `HudViewModel`, `HudFighterView`, `HudRoundView`, `createHud(options?): Hud`, `Hud`, `HudOptions`
**Depends on:** `modules/i18n.md` (`t`, `onLocaleChange`), `modules/rendering.md` (`DEFAULT_HEALTH`, `MAX_POWER` placeholder constants from `match-config.ts`)
