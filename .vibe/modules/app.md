# Module: app
**Role:** Composition root. Builds the `web-ui-kit` app shell — including a `<wuik-locale-switcher>` in the toolbar (backlog item 009) — then calls its own `showRosterSelection` helper (discovers the character roster, mounts the character selection screen), then — once both players continue — discovers the stage list and mounts the stage selection screen, then — once a stage is chosen — mounts the match setup screen, then — once setup is confirmed — re-fetches and re-loads both players' character files (including each one's own `.cmd` input command file and, when the manifest declares one, `.snd` sound file — backlog item 013) and the chosen stage's file (including its background music file, when its `.def` declares one, resolved by basename against the stage `.def`'s own directory the same way its `.sff` sheet already is — backlog item 013; discovery itself never retains raw bytes/full data, only the name), threads the setup screen's CPU-opponent choice through, and starts match rendering with a working `onBackToSelect` callback wired to re-invoke `showRosterSelection` fresh (backlog item 007's match result screen). A fetch/load failure at that point degrades to a clear, translated error message, same handling used at every earlier screen boundary — except a `.cmd`/`.snd` file's own fetch/parse failure, or a stage's music file failing to fetch, each of which degrades only that one thing (no recognized commands, no sound effects for that fighter, no background music) rather than blocking the match. The real bootstrap (`mount()`, module-scope) awaits `initAppI18n()` before the first `renderApp` call, so the very first paint already has the right language; `renderApp` itself stays synchronous-callable so tests can call it directly without bootstrapping i18n. The toolbar's own locale-change subscription only retranslates the locale switcher's accessible label — the brand title/version are untranslated proper nouns, and each screen's own text is retranslated by that screen itself (see `modules/i18n.md`, `modules/selection.md`, `modules/setup.md`).
